# Claude PR Practice

Welcome! This repository exists so I can practice the full GitHub workflow:
creating a branch, committing a change, and opening a Pull Request.

## What is this?

A minimal sandbox repo. Its content isn't important — what matters is
practicing the process of proposing and merging changes safely through PRs.

## Workflow

1. Create a branch off `main`.
2. Make a small, focused change.
3. Push the branch and open a Pull Request.
4. Review and merge.
